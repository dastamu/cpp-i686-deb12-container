# cpp-i686-deb12-container

> C/C++ Hello World 32-bit in container

# Dependences
```sh
# Debian
apt update && apt upgrade
apt install podman podman-compose
```

# Download
```
git clone git@github.com:dastamu/cpp-i686-deb12-container.git
```

# Run
```sh
cd cpp-i686-deb12-container

# Build container image
sh build.sh

# Compile application
sh make.sh
# or
sh cmake.sh

# Run application
sh run.sh
' * Hello World z wieloplikowego projektu C++ (Podman + Make/CMake na Debian 12 32-bit)! * '
```
