# cpp-i686-deb12-container

> C/C++ Hello World 32-bit in container

# Dependences
```sh
# Debian
apt update && apt upgrade
apt install podman podman-compose
```

# Download
```
git clone git@github.com:dastamu/cpp-i686-deb12-container.git
```

# Run
```sh
cd cpp-i686-deb12-container
sh build.sh
sh compile.sh
sh run.sh
```
